# Multiplayer operating memory

The owner explicitly chose both multiple users and collaborating agents on 2026-10-07. Implemented shared projects with editor/viewer credentials, named Pi agents, durable task ownership/results, append-only notes and SSE observation. Pi owns each private transcript/inbox; long-term hierarchical memory and VFS remain per agent. Shared evidence and authenticated member provenance are frozen at the tail of a new submission. No shared-store write rewrites established prompt prefixes.

Credentials are HMAC-verified in the Worker before a DO lookup, then checked against SQLite hashes/roles/revocation. They expire after thirty days; owner issuance with the same member id rotates the key without adding membership rows. Owner DEMO_TOKEN rotation invalidates all signed project credentials. Every host should get its own member token. Never put owner/Cloudflare/project credentials in git or chat.

Tasks run explicitly, one request per dispatch, with at most two deliberate attempts using one durable operation id. No recursive fan-out, recurring polling or automatic background dispatch. Agent tool permissions are immutable assignment metadata, enforced before effects while static declarations remain stable. Model policies do not replace human editor API authorization. Every project/agent shares unchanged global quotas and emergency controls; see BILLING.md before any change.

Hosted demonstration: project team-demo-1791364833714; builder published an exact handoff, reviewer read and explained it using team_board. Private team configurations/credentials live in /home/coder/.config/durable-agent-memory, including pi-team-builder and pi-team-reviewer launcher scripts. Existing T3 provider/chat configuration was preserved. Demo agents have intentionally restricted collaboration tools; owner-created agents default to the existing reviewed tools.

Verified 51 tests and local workerd scopes/revocation/tool denial/parallel tasks/restart/prefix/stop, plus hosted two-agent handoff and signed-credential read-only checks.
